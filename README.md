# Factorial Calculator

A simple Python application that calculates the factorial of a number entered by the user.

## Features

* Calculates the factorial of a positive integer
* Accepts input from the terminal
* Validates negative numbers
* Handles invalid user input
* Simple and beginner-friendly

## Requirements

* Python 3.x

> **Note:** NumPy is not required unless it is used in the program.

## Installation

1. Clone the repository.
2. Open the project folder in the terminal.
3. Install the required dependencies, if any:

```bash
pip install -r requirements.txt
```

## Usage

Run the program using:

```bash
python factorial.py
```

Enter a number when prompted:

```text
Enter a number: 5
```

Output:

```text
120
```

## How It Works

The program takes an integer as input and uses a loop to multiply all numbers from `1` to the given number.

For example:

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

The program also checks for negative numbers and invalid input to prevent errors.
